# reject / 編集要求フォーム

**Tally フォーム**（https://tally.so ・無料・回答側にアカウント不要）で構造化された reject・編集要求を受け付ける計画です。

## 設置手順（要ユーザー操作）

1. https://tally.so でフォーム作成（GitHub/Google で無料登録）
2. 項目を定義:
   - **対象ページ URL**（必須）
   - **対象 claim ID / 伏線 ID**（任意）
   - **種別**（reject / 事実誤り / 編集提案 / 情報提供）— ラジオボタン
   - **理由**（必須・テキストエリア）
   - **典拠**（章・ページ番号・引用）
   - 投稿者名（任意・匿名可）
3. フォーム公開 → 本ページと各 Wiki ページ下部に「誤りを報告」リンクを設置

## 処理パイプライン（Phase 2）

```
フォーム回答 → cron 収集（Tally API / CSV export）
  → LLM トリアージ（妥当性判定・スパム分類・対象 run の特定）
  → 新 run 生成（run.json に contributed_by・source_form を記録）
  → 人間は承認 / reject のみ
```

## 設計原則

- ユーザー入力は**パイプライン経由のみ**で内容を反映する（ページ直接編集は不可）
- reject は「LLM 再審査トリガー」であり、来歴チェーン（L7→L3→L2→L1→L0）は切らない
